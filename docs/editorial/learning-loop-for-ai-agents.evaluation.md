## Issues

1. **Major, Clarity: sidecar missing `date`.** `docs/editorial/learning-loop-for-ai-agents.meta.json` has eight keys. `src/content/writing/index.ts` defines `date: string` as required on `Article` (only `series` is optional), and all ten other sidecars include it. Without it the entry cannot be added to `articles` without a type error, and the page has no publication date. **Fix:** add `"date": "YYYY-MM-DD"` with the intended publish date. `series` can stay absent since this is a standalone piece.
2. **Minor, Accuracy: Nosek venue and DOI not from a fetched page.** The sentence cites "PNAS 2018, DOI 10.1073/pnas.1708274114". The fetched manuscript does not carry the DOI or volume; the publisher page returns 403. The DOI does resolve (302) to pnas.org, so it is real, but the rule is that public-source facts come from a fetched page. **Fix:** either keep only the manuscript link and "Nosek and colleagues (2018)", or leave the DOI and note in the research file that it was confirmed by resolution only.
3. **Minor, Code: budget ignores headings.** In `render()`, `used` counts only item lines; the "# Context package" header and the "## ..." layer titles are not charged against `budget`. The prose says "The package has a character budget", which a reader will take to mean the whole package. **Fix:** add `used += len(title) + 5` when a layer is opened (and the header length at start), or say "a character budget for items" in the prose. Output is unaffected at budget 600 with this data.
4. **Minor, Clarity: length.** 2,771 words of prose against a 2,800 ceiling. Fine as is, but any addition in the next pass must be matched by a cut. Candidates: the second paragraph of "Repeatable batch runs" overlaps "Structure before code" in the production section.
