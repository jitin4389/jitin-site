# Intent: agentic coding article series (confirmed 2026-10-04)

- **Outcome:** Track A, a 10-part original practitioner series on agentic coding with Claude Code, in the site's Writing section. Portable Markdown per part, plus summary, key points and a video-script outline, so it can later be republished on Medium, LinkedIn, Discord and YouTube (lectures and Shorts).
- **Audience:** working developers and tech leads who already use AI assistants. Each part opens with an "In one minute" plain-language summary and definitions so juniors can follow.
- **Each part:** 1,500–2,500 words: concept, working example, anonymised "how I use this in production", pitfalls, checklist. Same-day useful.
- **Launch set:** (1) Context and CLAUDE.md, (4) MCP servers, (6) Hooks as guardrails. Then the remaining seven.
- **Production:** a multi-agent team (researcher, writer, editor, evaluator). The evaluator checks technical accuracy against official docs, originality versus the Udemy course (outline used as a topic map only), the confidentiality blocklist and approved-claims rules, and that code examples run.
- **Owner involvement:** near zero. Parts are published to a preview; one "publish" from the owner puts them live.
- **Out of scope now:** Track B (AI foundations for students and junior developers; tool-agnostic and age-appropriate; next candidate, likely first course), cross-posting, videos, newsletter, course packaging, and any reuse of the course's text, project or examples.
